
# Marvel · OpenKill UI 设计规范

> 一句话：**暗场、红金、锐利。** 像电影片头，也像漫画分镜。

## 1. 四条原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| 暗场 | 近黑背景，内容靠红与金跳出来 | 灰蓝渐变面板 |
| 一条红 | 全站只有一个 Marvel 红，负责动作与选中 | 多色状态灯 |
| 金只做标记 | 金色仅用于徽章、编号、警示 | 金色大面积铺底 |
| 锐利 | 直角、2px 边、无圆角 | 大圆角 + 阴影 |

## 2. 色板（Marvel）

| Token | 值 | 用途 |
| --- | --- | --- |
| canvas | `#0E0E10` | 主背景（近黑） |
| chrome | `#151517` | 侧栏、标题栏 |
| card | `#1B1B1F` | 卡片、输入框 |
| raised | `#24242A` | 次级块 |
| text | `#F4F4F5` | 正文（冷白） |
| text_dim / faint | `#C7C7CC` / `#9A9AA2` | 次级 / 注释 |
| accent | `#D91E24` | Marvel 红：描边、选中、进度 |
| warning | `#FFC000` | 金：徽章、编号、警示 |
| success | `#34C759` | 就绪状态 |
| border | `#D91E24` 2px | 卡片与控件描边 |

## 3. 字体与版面

- 主标题 **36px**，上方等宽编号（`01 / MAKE`）。
- 正文 15px；数据与编号用 JetBrains Mono。
- 卡片内边距 20px，块间距 16–24px；左对齐。

## 4. 组件

| 组件 | 规范 |
| --- | --- |
| 卡片 | 暗底 + 2px 红框 + 直角，无阴影 |
| 选中态 | 红框 + 暗红底 `rgba(217,30,36,0.20)` |
| 主按钮 | 亮色填充；危险动作红 |
| 徽章 | 黑底金字或红底白字，等宽字 |
| 弹窗 | 暗底 + 2px 红框 |

## 6. 验收

- 无圆角；卡片统一红描边。
- 强调色只有 Marvel 红；金色只出现在徽章/警示。
- 正文对比度 ≥ 4.5:1，边框 ≥ 3:1（theme.rs 单测覆盖）。
- 主题开关五档：Studio / Light / Brutal / Pop / **Marvel**，默认 Marvel。

## 7. 漫画化细节（本轮）

- **切角卡片**：主内容卡与检查卡在左上角切出 26px 红色三角（Marvel 专属）。
- **全大写标题**：Marvel 下主标题自动转大写（`theme::display`），其它主题保持句首大写。
- **2px 描边**：卡片、控件、窗口统一使用 token 的描边宽度。
