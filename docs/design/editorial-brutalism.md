
# Editorial Brutalism · AutoKili UI 设计规范

> 一句话：**用杂志的排版纪律，做软件的骨架。** 纸、墨、一条朱红，剩下全是结构。

## 1. 三条原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| **结构可见** | 边框、分隔线、编号就是导航，不靠阴影和圆角暗示层级 | 悬浮卡片、渐变、玻璃拟态 |
| **排版即品牌** | 大标题、栏目标号、页脚行构成识别度 | 靠 logo 和配色识别 |
| **一种强调色** | 全站只用一条朱红表达"动作 / 选中 / 危险" | 多色状态灯 |

## 2. 色板（Editorial 主题）

| Token | 值 | 用途 |
| --- | --- | --- |
| canvas | `#F3F0E8` | 主阅读面（纸） |
| chrome | `#E9E4D8` | 侧栏、标题栏 |
| card | `#FFFDF7` | 卡片、输入框 |
| raised | `#E4DFD2` | 次级块、代码底 |
| text | `#111111` | 正文（墨） |
| text_dim / faint | `#333333` / `#5A5A5A` | 次级 / 注释 |
| accent | `#C9340F` | 朱红：主动作、选中、焦点 |
| accent_ink | `#8F230C` | 朱红文字（链接） |
| separator / border | `#111111` | 1px 墨线 |
| danger / warning / success | `#A31D14` / `#8A5A00` / `#1F6B3A` | 语义色，仅用于文字与小标记 |

规则：

- **禁止阴影**（shadow 透明）、**禁止圆角**（radius 全 0）。
- 边框一律 **1px 实线**，颜色用墨而非灰。
- 强调色覆盖面积不超过屏幕 5%。

## 3. 字体

| 角色 | 字体 | 用法 |
| --- | --- | --- |
| 标题 / 正文 | DM Sans（Regular / Medium / Bold） | 栏目名、正文、按钮 |
| 数据 / 编号 / 路径 | JetBrains Mono | 工具 ID、偏移、文件名、日志 |
| 大标题 | DM Sans Bold，字号 ≥ 28 | 每页唯一一个 |

排版纪律：

- 大标题左对齐，紧贴上边距，**不加装饰**。
- 栏目标号用等宽字体：`01` `02` `03`，与标题同一基线。
- 小标签全大写（或中文短词）+ 字距放宽；egui 不支持字距，用字号与空白替代。
- 正文行长控制在 60–75 字符。

## 4. 网格与间距

- 基线 8px；间距只用 8 / 16 / 24 / 32 / 48。
- 左右留白 ≥ 32px；栏与栏之间用 1px 墨线分隔，不用留白暗示。
- 卡片是"区块"不是"浮层"：直角、墨线、无投影、内部 16px。

## 5. 组件规范

| 组件 | 规范 |
| --- | --- |
| 按钮 | 直角矩形；主按钮朱红底 + 纸色字；次按钮纸底 + 1px 墨线 |
| 输入框 | 纸底、墨线、直角；聚焦时墨线变朱红 2px |
| 表格 | 只有横线，无竖线；表头全大写小号 |
| 标签 / 徽章 | 直角、1px 墨线、等宽字；状态用文字而非纯色点 |
| 卡片 | 标题 + 编号 + 1px 分隔线 + 内容 + 页脚行 |
| 弹窗 | 纸底、2px 墨线、无圆角、无阴影 |
| 滚动条 | 细、方、墨色 |

## 6. egui 落地方式

主题层（`crates/ui-egui/src/theme.rs`）：

- `ThemeKind::Editorial` 提供一套 `Tokens`：radius = 0、shadow = 透明、accent = 朱红。
- `Tokens::for_kind` 是唯一色源；控件不自带颜色。
- 设置页三段开关：Studio / Light / Brutal；`Ctrl+K → Toggle theme` 三态循环。

2. 表格化列表：去掉卡片阴影，改横线表格。
3. 空态与加载态：用文字与线框，不用插画。

## 7. 验收标准

- 截图中不出现圆角与阴影。
- 任意页面只有一种强调色。
- 每个页面有一个 ≥28px 的标题和一个等宽编号。
- WCAG AA：正文对比度 ≥ 4.5:1，控件边框 ≥ 3:1（theme.rs 内已有单测）。
