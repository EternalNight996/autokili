
# Pop Art · AutoKili UI 设计规范

> 一句话：**平涂的色块、粗黑的描边、硬邦邦的投影、一条红。** 像印在纸上的漫画。

## 1. 五条原则

| 原则 | 含义 | 反例 |
| --- | --- | --- |
| **平涂** | 一个区域一个颜色，没有渐变、没有透明度层次 | 毛玻璃、渐变按钮 |
| **粗描边** | 2.5px 纯黑线勾勒每个控件 | 1px 浅灰细线 |
| **硬投影** | 偏移 3px 的纯黑影子，blur = 0 | 羽化阴影 |
| **三原色** | 黄、红为主，白纸为底 | 莫兰迪色、低饱和 |
| **半调点** | 大块留白用网点打破 | 纯色大平面 |

## 2. 色板（Pop）

| Token | 值 | 用途 |
| --- | --- | --- |
| chrome | `#FFD84D` | 标题栏、侧栏（黄） |
| canvas | `#FFF3D6` | 主阅读面（奶油） |
| card | `#FFFFFF` | 卡片、输入框 |
| raised | `#FFE9A8` | 次级块、代码底 |
| text | `#111111` | 墨黑 |
| accent | `#D42A25` | 正红：选中、链接、进度 |
| separator / border | `#111111` | 2.5px 黑描边 |
| shadow | `#000000` 实心 | 硬投影，偏移 3px |

规则：描边统一 2.5px；圆角全 0；阴影 blur 必须为 0。

## 3. 字体与版面

- 主标题 **36px**（DM Sans Bold），上方一行等宽小字栏目编号：`01 / MAKE`。
- 正文 15px，数据/编号用 JetBrains Mono。
- 版面左上对齐，卡片内部 20px，块间距 16–24px。

## 4. 组件

| 组件 | 规范 |
| --- | --- |
| 卡片 | 白底、2.5px 黑框、直角、右下 3px 黑硬投影 |
| 主按钮 | 墨黑底 + 白字；危险动作用正红 |
| 输入框 | 白底黑框；聚焦黑框变红 |
| 选中态 | 红框 + 淡红底 `rgba(212,42,37,0.16)` |
| 标签 | 黑框、等宽字、直角 |
| 弹窗 | 白底、2.5px 黑框、硬投影 |

## 5. 图标

- 主题：⚔️ 交叉双剑 + 黄色爆炸星 + 红色半调点 + 黑外框。
- 源文件：`tools/icon/gen_openkill_icon.py`（Pillow 生成 PNG / ICO / ICNS / SVG）。
- 替换上游 ArtCraft 的 raven（上游许可证要求二创必须更换图标）。

## 7. 验收

- 截图里没有圆角、没有羽化阴影。
- 每个控件都有黑描边；强调色只有一种红。
- 首屏有 36px 主标题 + 等宽编号。
- WCAG AA：正文 ≥4.5:1，边框 ≥3:1（theme.rs 单测覆盖）。

## 8. 漫画细节（与 Marvel 共用）

- 主内容卡与检查卡左上角切出 26px 红色三角。
- 主标题自动转全大写（`theme::display`）。
- Pop 为默认主题；Marvel 是同一套漫画细节的暗色版。
