# AutoKili app icon

Pop-art crossed swords: cream paper `#fff3d6`, yellow starburst `#ffd84d`, loud red
`#d42a25`, ink outlines `#111`, a 30-unit black frame and (PNG only) red halftone dots.

Generated by `tools/icon/gen_openkill_icon.py` (Pillow). It replaces the upstream ArtCraft
"raven" icon, which the upstream licence requires forks to replace with their own artwork.

## Files

- `craft-anything.svg`: master SVG (also the hicolor scalable icon).
- `craft-anything-1024.png`: 1024 px render.
- `craft-anything.icns`: macOS icon (PNG-chunk ICNS, 16-1024).
- `craft-anything.ico`: Windows icon (16-256).
- `hicolor/<size>/apps/ai.storyteller.craft-anything.png` and
  `hicolor/scalable/apps/ai.storyteller.craft-anything.svg`: Linux icon theme.

## Regenerate

```bash
python tools/icon/gen_openkill_icon.py
```
