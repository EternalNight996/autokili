# AutoKill app icon

The mark: a rounded near-black tile (#101014) with a bold "AK" monogram in #4E7BFB and a #1659C4
rule under it. Original to this fork, MIT OR Apache-2.0 (see LICENSE.txt).

| File | Used by |
|---|---|
| `autokill-1024.png` | the repository logo, eframe window icon source |
| `autokill.svg` | vector source, web and docs |
| `autokill.ico` | Windows executable resources (16-256) |
| `autokill.icns` | macOS app bundle |
| `hicolor/<N>x<N>/apps/ai.autokill.app.png` | Linux, freedesktop icon theme |

Every file is generated by `build-icons.ps1` (PowerShell 5.1 + System.Drawing, no extra tools):

```powershell
powershell -ExecutionPolicy Bypass -File build-icons.ps1
```

Change the colours or the letters at the top of that script and re-run it; do not hand-edit the
PNGs.
