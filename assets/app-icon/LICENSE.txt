AutoKill app icon

The AutoKill mark (a rounded dark tile with an "AK" monogram) was drawn for this project and is
released under the same MIT OR Apache-2.0 licence as the code (LICENSE-MIT, LICENSE-APACHE).

It replaces the upstream ArtCraft icon (the raven), which this fork neither uses nor redistributes.
The generator that draws every size is build-icons.ps1 in this folder.
